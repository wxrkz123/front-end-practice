# 前端基础练习

HTML / CSS / JavaScript 入门练习合集，每个文件对应一个知识点，按编号顺序学习即可。直接用浏览器打开对应的 `.html` 文件就能看到效果。

## 目录

| # | 文件 | 知识点 |
| --- | --- | --- |
| 1 | `1.html文本标签.html` | 标题、段落、文本格式化标签 |
| 2 | `2.html属性.html` | 常用 HTML 属性 |
| 3 | `3.html区块.html` | 块级 / 行内元素、`div` 与 `span` |
| 4 | `4.html表单.html` | 表单与输入控件 |
| 5 | `5.css导入方式.html` | 行内、内部、外部样式表 |
| 6 | `6.css选择器.html` | 各类选择器 |
| 7 | `7.css常用属性.html` | 字体、颜色、背景等常用属性 |
| 8 | `8.css盒子模型.html` | margin / border / padding / content |
| 9 | `9.浮动.html` | float 布局与清除浮动 |
| 10 | `10.定位.html` | relative / absolute / fixed / sticky |
| 11 | `11.JavaScript导入方式.html` | 内联、内部、外部脚本 |
| 12 | `12.JavaScript的基本语法.html` | 变量、数据类型、运算符、流程控制 |
| 13 | `13.JavaScript事件处理.html` | 事件绑定与处理 |
| 14 | `14.DOM.html` | DOM 查询与操作 |
| 15 | `15.practice.html` | 综合练习 |
| 16 | `16.rem.html` | rem 单位与移动端适配 |
| 17 | `17.flex.html` | Flex 弹性布局 |

辅助文件：`style.css`（外部样式示例）、`myscript.js`（外部脚本示例）、`table.js`（表格相关脚本）。

## 使用

```bash
git clone https://github.com/wxrkz123/front-end-practice.git
cd front-end-practice
# 直接双击 html 文件，或用 VS Code 的 Live Server 打开
```
